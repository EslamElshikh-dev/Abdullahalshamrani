# مكتب عبدالله عبدالرحمن الشمراني للتجارة والمقاولات

موقع عربي ثابت وسريع لمكتب مقاولات عامة في الرياض. يشمل:

- صفحة رئيسية وهوية كحلية/ذهبية وصورة المحل الأصلية.
- 12 صفحة خدمة مستقلة بمحتوى SEO وثمانية أسئلة شائعة لكل خدمة.
- مدونة داخلية تضم مقالات متخصصة في البناء والتشطيب والصيانة والتوريد.
- مساعد تفاعلي مكتوب بـ Vanilla HTML/CSS/JS ويرسل الطلب إلى واتساب.
- صفحة للشهادات والوثائق مع معاينة مكبرة للصور الأصلية.
- بيانات منظمة HomeAndConstructionBusiness وService وBlogPosting وFAQPage.
- خريطة Google والعنوان وساعات العمل وبيانات النشاط المتطابقة.
- sitemap.xml وrobots.txt وRSS وManifest.

## الأوامر

    npm run build
    npm run validate
    npm test

يولد أمر البناء النسخة النهائية داخل dist ويصدر نسخة Markdown مجمعة من المحتوى داخل content/seo-content.md.
