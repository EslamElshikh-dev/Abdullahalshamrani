# مكتب عبدالله عبدالرحمن الشمراني التجارية

موقع عربي ثابت لمحل مواد بناء وديكورات جبسية في الرياض، مع صفحات خدمات المقاولات والتشطيب والتوريد. يشمل:

- صفحة رئيسية وهوية كحلية/ذهبية وصورة المحل الأصلية.
- صورة الواجهة الأصلية بدقة 1385 × 1536 بكسل للبيانات المنظمة ومعاينة المشاركة، مع نسخة محسنة لعرض الصفحة.
- 12 صفحة خدمة مستقلة بمحتوى SEO وثمانية أسئلة شائعة لكل خدمة.
- مدونة داخلية تضم مقالات متخصصة في البناء والتشطيب والصيانة والتوريد.
- مساعد تفاعلي مكتوب بـ Vanilla HTML/CSS/JS ويرسل الطلب إلى واتساب.
- صفحة للشهادات والوثائق مع معاينة مكبرة للصور الأصلية.
- بيانات منظمة HardwareStore وWebSite وWebPage وBreadcrumbList وService وBlogPosting، تربط الصفحات بكيان نشاط واحد.
- خريطة Google والعنوان والهاتف والاسم القانوني المطابق لبيانات الملف والمستندات.
- مواعيد زيارة المحل تُؤكد بالتواصل؛ لا تُنشر ساعات غير مؤكدة في المحتوى أو السكيما.
- sitemap.xml وrobots.txt وRSS وManifest.

## الأوامر

    npm run build
    npm run validate
    npm test

يولد أمر البناء النسخة النهائية داخل dist ويصدر نسخة Markdown مجمعة من المحتوى داخل content/seo-content.md.

الأسئلة الشائعة متاحة للزوار داخل الصفحات. أوقفت جوجل عرض نتائج FAQ الغنية في مايو 2026، لذلك لا يُصدر البناء نوع FAQPage. تُستخدم بصمات محتوى لروابط CSS وJavaScript حتى تصل التحديثات إلى الزوار الذين يحتفظ متصفحهم بنسخ سابقة.
